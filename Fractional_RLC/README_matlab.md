Place `rlc_fractional_study.m` in the MATLAB current folder and run:

```matlab
results = rlc_fractional_study;
```

The function uses core MATLAB operations and does not require Control System Toolbox or any other optional toolbox. To omit figures, run `results = rlc_fractional_study(false);`. To choose the destination, run `results = rlc_fractional_study(true, 'my_results');`.

The default output directory is `matlab_results` inside the current folder. It contains four plots (`transient`, `tail`, `frequency`, and `convergence`) in PNG and PDF, `metrics.csv`, `classical_error.csv`, `mesh_validation.csv`, `laplace_validation.csv`, and `results.mat`. The convergence plot compares each mesh with an embedded table of independently inverted Laplace values at dimensionless times 0.25, 1, 2, 4, 10, 20, 30, and 60. The table was generated with Python's `mpmath` de Hoog inversion method at 35 decimal digits and can be regenerated by the accompanying Python implementation. MATLAB requires no inverse-Laplace toolbox. Two further CSV checks compare coarse solutions with the finest mesh over every shared time point and compare the classical solution with its analytical expression over the entire record.

The study applies full-history backward-Euler convolution quadrature to the zero-state Caputo model. It uses orders 0.8, 0.9, and 1.0; dimensionless steps 0.01, 0.005, and 0.0025; a 60 ms horizon; a 1 V step; `tau = 1 ms`; and `Z0 = 10 ohm`. The finest physical time step is 2.5 microseconds. At order 1, the circuit values are R = 10 ohm, L = 10 mH, and C = 100 microfarads. Orders below 1 describe ideal fractional elements with the same normalization. They do not describe an ordinary RLC circuit with different component values.

The solver keeps the entire history, so runtime grows quadratically with the number of time samples. A complete run can take several minutes depending on the computer. The starting states are exactly zero. At order 1, the same recurrence reduces to backward Euler; it is intentionally still numerical, permitting an independent comparison with the exact classical transient.

CSV voltage errors use volts, current errors use amperes, and timing metrics use milliseconds. Overshoot is measured against the final normalized voltage 1. Peak time is `NaN` when no above-final-value peak is observed. The 10–90% rise time interpolates the first threshold crossings. Settling times use the last exit from a 2% or 1% band within the finite simulated record, then interpolate the final boundary crossing. `NaN` means the criterion was not reached within that record. These estimates do not prove that a response remains inside its band for all future time.

The simulations represent the mathematical model, not measured hardware data. MATLAB was unavailable in the preparation environment: this `.m` file was inspected for syntax, indexing, units, and algorithmic consistency, but no MATLAB runtime verification is claimed. The paper's reported curves and numerical results were generated by the accompanying Python implementation and checked with an independent numerical inverse Laplace transform and the exact order-1 solution. Small last-digit differences from a MATLAB run may reflect floating-point summation and interpolation.
